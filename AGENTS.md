Read this file, [CURRENT-TASK](CURRENT-TASK.md), [architecture](docs/ARCHITECTURE.md), [latest checkpoint](docs/LATEST-WORK.md). Read only applicable subsystem contracts. ## Durable rules
- Work on dev/resolver-profiler-handoff; use existing dev/native-fixed-cache-player-state only for its native source/build ownership. No unnecessary branches, stable release changes or version bumps. Verify HEAD and avoid overwriting concurrent changes.
- CET owns native/Lua instrumentation, standalone lifecycle and Resolver/generator. GCO orchestrates, GRSP profiles REDscript, GCO owns its managed REDscript Resolver, G-REDruntime owns shared REDscript services.
- One canonical namespaced Scheduler: modules/G-CET/Scheduler.lua. Source-proven root alias returns the same module; foreign hosts untouched. Profiler uses canonical hooks without duplicate scheduler/live host injection when present; legacy adaptive integration only when appropriate. Restore preserves Resolver-owned files.
- One generation from current untouched supported source: generic 0-Engine -> native integration -> generic finalization -> source-aware semantics. Semantic requirements may inform earlier stages, never require already-generated semantics. Fix existing generators at source; no corrective pass or duplicated worker.
- Discover real live owners/dependencies; capture is evidence, not inventory. Recognize stock, partial, complete and compatible custom/newer/older source structurally; generate missing parts only. Unknown unsafe operation refuses narrowly with exact reason. Preserve author callbacks, lifecycle, timing, fallbacks, external worker ownership, Lua local budget and syntax. No version/hash locks on mods.
- Use actual private untouched sources and fixed CI capture for reproducibility; never publish third-party original files, captures or credentials. For missing required source report exact game-relative path. Never substitute historical optimized files as originals.
- Prioritize measured recurring native/Lua work, allocation ops and bytes, GC and hitch severity. Do not infer retained heap, ownership or causal gain from overlapping timing or marker presence. Use the [Phase 3 interpretation contract](docs/phase3/PHASE3-ALLOCATION-CONTROLL.md) when analyzing captures; respect user-confirmed controlled tests and label specific missing counters NOT_MEASURED.
- Validate actual composed generation, Lua execution, source compatibility/partial completion and rerun zero changes. Inspect dependencies, behavior and ownership; preserve all high-value CI contracts. Green CI is not game/runtime/performance proof.
- Native rebuilds deliberate/manual only for changed generating source. Package CI imports exact verified source/run/artifact/hash, not unverified native revisions. Preserve profiler and Resolver package independence; see [build pipeline](docs/HANDOFF/BUILD-PIPELINE.md). No docs-only CI or routine native rebuilds. No version change without owner approval.
- Keep one canonical Scheduler demand controller. Preserve freshness, exact deadlines, sync getters, event and lifecycle dependencies. Do not manufacture savings by suppressing profiler evidence. Apply source-proven reductions, not blanket throttling or new per-mod schedulers.
- Update the concise checkpoint after material work. Continue independent approved steps; do not convert a candidate decision or pending game test into an arbitrary project-wide stopping gate.
