## Blocking source and safety findings

- **The original observer serves more than the ActionRouter.** User-supplied 0-Engine `init.lua` has one `Observe('PlayerPuppet','OnAction')` callback that executes `ActionRouter.Dispatch(...)` and may subsequently call **`Events.PlayerAction:trigger(action)`** when playing and outside menus. An exact-action router miss does **not** prove the *whole* observer is unnecessary. Dynamic legacy event listeners, original order and wake paths must be inspected against the **currently installed** source.
- Other mods register their own `PlayerPuppet::OnAction` callbacks or original fallbacks; no **global** OnAction suppression, native engine-method short circuit, or arbitrary callback reordering is permissible.
- In native CET source, examine the real `FunctionOverride` / `RealRunScriptFunction` subscriber dispatch and argument conversion sequence. An action CName must be read safely **before** per-observer Lua argument construction for a pre-marshalling saving to exist; a method hash, RTTI guess or Lua-side skip after conversion is insufficient. Unknown action/type, subscriber identity, snapshot, session, or observer state must **deliver the original callback**.
- Subscription interest changes (`Subscribe`, `SetActive`, `Pause`, `Resume`, `Cancel`, reload), wildcard and legacy event paths invalidate old native decisions **before** effective membership changes. Runtime delivery fails open; admission and release fail closed.
- Quest-specific dormancy and the generic static-location/RED4ext cache are **not this task**. Do not accidentally restore deferred cache code while working on native/Lua crossings.
