# Native static-location shared service — new experimental CI line (2026-10-16)

Decision: support **50+ potential CET mods plus a separately audited REDscript stack**, without assuming all are installed. Only source-proven fixed positions in the **current installation** are eligible. Native RED4ext C++ owns the index. A source-only Resolver recognizer/semantic stage will eventually produce the per-installation compact manifest and adapt original subscriber/first-interaction wake behavior. Lua and REDscript must **not** maintain their own duplicate coordinate cache. YAML is suitable for human-visible review, but compiled GCAS v1 records are the only runtime data format.

Implementation is isolated on `dev/native-static-anchors-experimental`. Core files under `native-static-locations/` implement XY or XYZ sphere checks, 128m spatial hash, owner IDs, arm/disarm, session invalidation, latest batch transitions, unknown/fail-open state, frozen manifest compiler, native RTTI declaration example and test suites. `.github/workflows/native-static-locations.yml` is an independent CI workflow; no modification to primary `dev/resolver-profiler-handoff`, pinned Profiler DLL, native Profiler CI, standard app CI, or v1.2.7 product fields.

**This is NOT the finished generic Resolver transformation**: source-proven safe candidate recognition, installed-mod selection, exact one-pass pristine/live/partial adapters, single player coordinator with both RED and CET consumers, long-lived transition queue semantics, win64 plugin compilation/test and actual in-game profile/quest validation remain outstanding. Delivery policy: separate build artifact containing `red4ext/plugins/G-CET-StaticLocations/GCETStaticLocations.dll` with SHA; eventually the Resolver ships that checked payload and compiled installed-only location file when an eligible source transform is accepted. No sample data, all-mod global list or REDscript declarations are installed by this experimental CI.

The preceding [R4 Lua/0-Engine experiment](STATIC-ANCHOR-RUNTIME-EXPERIMENT.md) remains reference evidence for ten mod candidate safety patterns, not the native implementation or an automatic source pass. [Cache capture comparison](STATIC-ANCHOR-CAPTURE-COMPARISON-20261016.md) is scenario-confounded; do not claim aggregate FPS gain. Remote quest activation, active scenes, cleanup and correct close-to-edge wake remain author-owned.
