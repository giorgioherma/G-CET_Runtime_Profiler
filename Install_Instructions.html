G-CET Runtime Profiler

v1.0.0 — Installation, capture and restore guide

SETUP → INSTALL → CAPTURE → COLLECT → RESTORE

0-Engine — heavily recommended

G-CET works without 0-Engine, but a compatible installation adds deeper Scheduler analysis: jobs, bursts and Scheduler attribution. Supported integration is intended for Pure CET releases v0.17.2 and newer.

Download DigitalVixen's 0-Engine on Nexus Mods

Frame-time profiler — heavily recommended

Pairing G-CET with a frame-time capture lets the report compare CET/Lua activity with actual rendered-frame behavior. G-CET v1.0.0 was tested with CapFrameX Pre-release v1.9.1 Beta (build 1.9.1.2).

Click to download CapFrameX on GitHub
Capture-key check: G-CET uses F11 as the initial default and attempts to seed that binding when no CET profiler binding already exists. Existing or user-changed CET bindings are left alone. Before every benchmark, double-check that CET and your frame-time profiler use the same capture key.
1

SETUP

  1. Select the Cyberpunk 2077 game folder. Click the first highlighted Browse... button and point G-CET to the Cyberpunk 2077 root folder.
  2. For the most useful results, keep Run with a frame-time capture tool enabled.
  3. Select your frame-time profiler executable. CapFrameX is the tested reference, but G-CET itself does not require it.
  4. Select the folder where that profiler saves captures/results.
  5. Review the displayed capture-key information, make sure CET and the frame-time profiler use the same key, then click CONTINUE.
Tip: if the tool reports an unknown or different frame-time key, correct it before capturing. F11 is the G-CET default, not a requirement.
2

INSTALL THE PROFILER

  1. Enter a useful Capture title such as WORLD, CITY_DRIVE or COMBAT. Save it when needed.
  2. Click INSTALL PROFILER.

G-CET temporarily deploys the profiling CET components and prepares the restore state. It can profile CET without 0-Engine, but 0-Engine is heavily recommended because compatible installations add Scheduler-level data that the core CET layer cannot provide.

Do not launch the game yet. Wait until the next page clearly reports PROFILER IS READY!.

3

READY — START THE TEST ENVIRONMENT

  1. If you are using one, start the frame-time capture tool first with START FRAME-TIME TOOL.
  2. Then launch the game with START CYBERPUNK.

For repeatable benchmark results, close unnecessary background applications before the capture: browsers, media players, updaters and other software that can create CPU, disk or GPU activity. Leave only software required to run Cyberpunk and record the test.

Once in the exact test location/scenario, press your shared capture key once to START. Run the workload. Press the same key again to STOP + EXPORT.

Consistency matters: for before/after testing, use the same route, scene, duration, graphics settings, game state and capture procedure wherever possible.
4

COLLECT THE CAPTURE

  1. After STOP + EXPORT, return to G-CET. Live Files should show that profiler output is present.
  2. Click COLLECT RESULTS / CLEAR LIVE.

The captured results are collected from the live game folder and stored under G-CET's RESULTS folder. G-CET then generates:

  • CET_Report.html — the main human-readable report.
  • CET_Summary.json — condensed machine-readable analysis.
  • All underlying raw profiler data.

If a recognized CapFrameX capture is available from the configured results folder, G-CET also adds the frame-time/correlation layer.

5

RESTORE ORIGINAL STATE

When you are finished profiling, close Cyberpunk 2077.

Then click RESTORE ORIGINAL STATE. This returns the G-CET-managed CET/0-Engine files to their normal state and removes temporary profiling components. Your current CET capture-key choice remains under your control.

Do not leave the profiling deployment installed for normal gameplay. Treat RESTORE ORIGINAL STATE as the final step of every finished profiling session.
6

CONFIRM RESTORE SUCCESS

Wait for the green confirmation:

✓ RESTORE SUCCESSFUL — profiler removed and original state restored.

Once this message is shown, the profiling session is complete. You can close G-CET and review the collected report from the results folder.

Vortex users

Because G-CET temporarily replaces/restores managed CET or compatible 0-Engine files during profiling, Vortex may occasionally report External Changes afterwards.

If that happens after a successful G-CET restore, use Revert all changes / the staged Vortex files so Vortex redeploys its managed copies. Do not use Save all changes to copy the temporary game-folder state back into Vortex staging.
